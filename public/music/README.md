# 🎵 Hướng dẫn thêm nhạc nền

Thêm file nhạc MP3 của bạn vào thư mục này với tên: `background.mp3`

Ví dụ: `/public/music/background.mp3`

Sau đó trong file `src/config.ts`, đảm bảo:

```ts
musicSrc: "/music/background.mp3",
```

## Gợi ý nhạc

- Nhạc nhẹ nhàng instrumental, lo-fi, hoặc acoustic
- Nhạc piano romantic
- Nhạc có tiếng đàn tranh hoặc âm hưởng Á Đông
